01 / 11 The Problem

Claude can write.
Can it ship?

  • → Most Claude Code sessions: write code, you run it manually, report back
  • → Claude has no eyes — it can't see if the change actually worked
  • → You are the feedback loop. That doesn't scale to full features.
Writing code and shipping a feature are two different things.
The gap between them is you.
02 / 11 The Gap

What being
the glue looks like

Without a running stack
  • Claude writes code
  • Start backend manually
  • Load env vars manually
  • Start frontend manually
  • Open browser, check it
  • Report back to Claude
  • Repeat every change
With a running stack

04 / 11 Under the Hood

What happens inside
that command

setup-environment.sh — pulls secrets from AWS SSM, resolves template into .env.develop. No manual credentials ever.
↓
run-backend.sh — sources .env.develop, starts uvicorn. Firebase, Snowflake, AWS all connected.
↓
health check loop — frontend waits until GET /health returns 200. No race conditions. No silent failures.
↓
run-frontend.sh — Vite dev server with hot reload. Claude's code changes appear in browser instantly.
05 / 11 Secrets Without Ceremony

The environment
template system

Template (checked into git)

FIREBASE_PROJECT_ID=
  {{SSM:/sedric/dev/firebase/project}}

SNOWFLAKE_ACCOUNT=
  {{SSM:/sedric/dev/snowflake/account}}

OPENAI_API_KEY=
  {{SSM:/sedric/dev/openai/key}}

resolve_env.sh produces .env

FIREBASE_PROJECT_ID=
  "sedric-develop-abc123"

SNOWFLAKE_ACCOUNT=
  "xy12345.us-east-1"

OPENAI_API_KEY=
  "sk-proj-..."
Secrets stay in AWS SSM. Templates live in git. No .env files ever committed.
New engineer: run setup once. Claude: run setup once. Same result, every machine.
06 / 11 The Contract

CLAUDE.md as
operating manual

CLAUDE.md
## 🚨 CRITICAL: SERVER STARTUP — NEVER DO IT ANY OTHER WAY
MANDATE: Always start the development server using
npm scripts. NEVER start uvicorn directly.
## The ONLY Way to Start the Server
npm run setup:develop # first time only
npm run dev:develop # every time after
## NEVER Do These
❌ uvicorn main:app --reload
❌ source .env.develop && python main.py
❌ any manual attempt to start the server
DEMO
Start the stack → give Claude a task → watch it close the loop without us
